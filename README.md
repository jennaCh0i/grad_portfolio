# Jenna Choi — portfolio

Static site (plain HTML / CSS / JS, no build step), deployed on Vercel from `main`.
Design source: Figma "Portfolio-v4", page **IXD final**.

- `index.html` — landing page
- `styles.css` — tokens + layout
- `main.js` — project filters, header menus, and the contact links (`LINKS` at the top)
- `assets/work/` — project thumbnails

Run locally: `npx serve .` (or open `index.html` through any static server).
